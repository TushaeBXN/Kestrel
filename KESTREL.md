# Kestrel

Model-agnostic coding agent that runs in your browser. Configure
`KESTREL_BASE_URL` and `KESTREL_MODEL` to point at any OpenAI-compatible
endpoint (Hugging Face, Ollama, vLLM, LM Studio, Groq, Together, OpenAI).

This file is also read by Kestrel itself: put a `KESTREL.md` (or `AGENTS.md`)
in any workspace and its contents are appended to the agent's system prompt.
